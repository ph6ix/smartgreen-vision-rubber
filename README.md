# 🌳 สมาร์ทกรีน Vision Ai วิเคราะห์ใบยางพารา

ถ่ายภาพใบยางพารา 3 ตำแหน่ง (+ ลำต้น/หน้ากรีด ไม่บังคับ) ให้ AI (Gemini) ช่วยประเมิน
- **ธาตุอาหาร 8 ธาตุ**: N, P, K, Mg, Ca, B, Zn, Mn
- **โรค แมลง และอาการหน้ากรีด**: ใบร่วงไฟทอปธอรา, ใบร่วงชนิดใหม่ (Pestalotiopsis), ใบจุดก้างปลา, ราแป้ง, รากขาว, เส้นดำ/เปลือกเน่า, อาการเปลือกแห้ง ฯลฯ
- **แผนปุ๋ย** ตามอายุและสถานะการกรีด และสิ่งที่ควรทำทันที

เว็บ: https://smartgreen-vision-rubber.vercel.app · หน้าแรกรวมพืช: https://smartgreen-vision-ai-home.vercel.app

> ⚠️ ความรู้อ้างอิงและสูตรปุ๋ยในคำสั่ง AI (`lib/rubberService.js`) เป็น **ร่าง** จากหลักวิชาการทั่วไป
> ต้องให้ทีมนักวิชาการสมาร์ทกรีนตรวจทานก่อนเปิดใช้กับลูกค้า

## ตำแหน่งภาพ

| ช่อง | ตำแหน่ง | ใช้ดู |
| --- | --- | --- |
| `young` | ใบยอด / ฉัตรใบอ่อน | B, Zn, Ca, Mn · ราแป้ง แอนแทรกโนส |
| `mature` | ใบมาตรฐาน (ฉัตรล่างของกิ่งยอดในร่มเงา ใบอายุ 3-5 เดือน) | ตัวแทนสถานะธาตุอาหารของต้น |
| `old` | ใบแก่ / ใบล่างในทรงพุ่ม | N, P, K, Mg · ใบร่วง ใบจุด |
| `tree` (ไม่บังคับ) | ลำต้น / หน้ากรีด / โคนต้น | เปลือกแห้ง โรคหน้ากรีด รากขาว |

## โครงสร้าง

| ส่วน | หน้าที่ |
| --- | --- |
| `public/` | หน้าเว็บ: `index.html` (ตรวจใบ), `report.html` (ใบรายงาน A4 + บันทึกรูป), `js/`, `css/`, `assets/` |
| `api/analyze.js` | ฟังก์ชัน Vercel: รับภาพ → `lib/rubberService.js` |
| `api/save-sheet.js` | บันทึกผลลง Google Sheets (`lib/sheets.js`, `gas/Code.gs`) |
| `lib/rubberService.js` | คำสั่ง AI, ตรวจภาพก่อนวิเคราะห์, จัดรูปผล |
| `lib/rubberProducts.js` | ผลิตภัณฑ์สมาร์ทกรีนที่อนุญาตให้ AI แนะนำ (ตอนนี้ว่าง รอฝ่ายวิชาการ) |
| `lib/gemini.js`, `lib/modelRetry.js` | เรียก Gemini พร้อมลองใหม่อัตโนมัติเมื่อระบบหนาแน่น |
| `server.js` | เปิดเว็บทดสอบในเครื่อง http://localhost:8080 |

## ตั้งค่า Vercel (Environment Variables)

| ชื่อ | ค่า |
| --- | --- |
| `GEMINI_API_KEY` | คีย์ Gemini (ใช้ตัวเดียวกับแอปอ้อย/ปาล์มได้) |
| `GOOGLE_SHEETS_WEBHOOK_URL` | (ไม่บังคับ) URL เว็บแอปจาก `gas/Code.gs` ของชีตยางพารา |

## รันในเครื่อง

```bash
cp .env.example .env   # ใส่ GEMINI_API_KEY
npm install
npm start
```

## เพิ่มผลิตภัณฑ์สมาร์ทกรีน
แก้ `lib/rubberProducts.js` ตามตัวอย่างในไฟล์ และวางรูปสินค้าไว้ที่ `public/assets/`
